# ♟️ Projeto Xadrez em Java

Projeto de um jogo de xadrez desenvolvido em **Java**, executado diretamente pelo terminal.

O projeto foi desenvolvido para fins de estudo durante o curso **Java COMPLETO - Programação Orientada a Objetos + Projetos**, do professor **Nélio Alves**, na Udemy.

O objetivo foi colocar em prática os principais conceitos de Java e Programação Orientada a Objetos estudados durante o curso, reunindo esses conhecimentos na construção de uma aplicação completa.

## 🎯 Sobre o projeto

O programa simula uma partida de xadrez pelo terminal, permitindo que dois jogadores realizem seus movimentos por meio das coordenadas do tabuleiro.

Durante a partida, o sistema controla os turnos, valida os movimentos de cada peça, realiza capturas e identifica situações de xeque e xeque-mate.

Ao selecionar uma peça, o programa também mostra no tabuleiro quais posições estão disponíveis para aquele movimento.

## 🧠 Conceitos utilizados

Durante o desenvolvimento foram aplicados conceitos como:

* Programação Orientada a Objetos (POO)
* Classes e objetos
* Encapsulamento
* Herança e polimorfismo
* Classes e métodos abstratos
* Sobrescrita de métodos
* Matrizes e listas
* Enumerações
* Tratamento de exceções
* Exceções personalizadas
* Composição de objetos
* Regras de negócio e validações

## ♟️ Funcionalidades

O projeto possui:

* Tabuleiro completo de xadrez
* Movimentação específica de cada peça
* Alternância entre jogadores
* Validação de movimentos
* Indicação dos movimentos possíveis
* Captura de peças
* Controle das peças capturadas
* Detecção de xeque
* Detecção de xeque-mate
* Tratamento de jogadas inválidas

## 🛠️ Tecnologias utilizadas

* Java
* Eclipse
* Git
* GitHub
* Git Bash

## 🖥️ Execução

O jogo é executado pelo terminal e utiliza coordenadas do tabuleiro de xadrez para realizar as jogadas.

Exemplo:

`Origem: e2`
`Destino: e4`
